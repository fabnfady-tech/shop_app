# تطبيق إدارة محل الحيوانات الأليفة (Flet)

تطبيق بايثون بالكامل، بيشتغل من غير إنترنت ومن غير أي سيرفر - كل البيانات محفوظة محلياً في ملف SQLite واحد (`shop.db`).

## الشاشات (من القائمة الجانبية - دوس على أيقونة ☰ فوق يسار)

| الشاشة | الملف | الوظيفة |
|---|---|---|
| **بيع** (الافتراضية) | `sales_view.py` | نقطة بيع: بحث، تصنيفات، مربعات منتجات، كمية بالوزن (كيلو/قطعة)، خصم، بيع نقدي أو آجل، فاتورة برقم تسلسلي |
| المنتجات | `products_view.py` | قائمة الأسعار: اسم، سعر، مخزون، تصنيف، ووحدة (قطعة/كيلو) |
| المصروفات | `expenses_view.py` | مصروفات وسلف، مع دعم بنود شهرية متكررة (زي الإهلاك) بتتسجل تلقائي كل شهر |
| الإيرادات المؤجلة | `deferred_view.py` | العملاء اللي بيشتروا بالأجل: الاسم، رقم التليفون، المبلغ المستحق، وتسجيل السداد |
| المرتجعات | `returns_view.py` | تسجيل إرجاع منتج - بيرجع المخزون تلقائي |
| جدول الشهر | `monthly_view.py` | سجل كل فواتير الشهر، بحث بتاريخ معين، وعرض تفاصيل أي فاتورة |
| التقرير | `reports_view.py` | صافي الدخل اليومي: نقدي مقابل آجل محصّل، المصروفات، المرتجعات، وتنبيه المخزون القليل |

المنطق الخاص بقاعدة البيانات كله في `db.py`.

## ملاحظات على بعض التفاصيل

- **الكمية بالوزن**: في شاشة البيع، المنتجات اللي وحدتها "كيلو" بتتضاف بالكيلو الواحد، وبعدين تقدر تزود/تنقص بخطوات ربع كيلو من السلة (زرار + و -).
- **البيع الآجل**: لما تفعّل مفتاح "بيع آجل" في شاشة البيع، هيطلب اسم العميل ورقم تليفونه (إجباري)، وهيظهر في شاشة "الإيرادات المؤجلة" لحد ما تسجل إنه دفع.
- **رقم الفاتورة (السيريال)**: بيتولد تلقائي بصيغة `INV-00001`، `INV-00002`... مبني على رقم عملية البيع في قاعدة البيانات.
- **طباعة الفاتورة**: لو شغلت التطبيق بأمر `flet run --web main.py`، هتقدر تطبع الفاتورة مباشرة من زرار الطباعة بتاع المتصفح (Ctrl+P) لأن التطبيق بيبقى صفحة ويب فعلية. الطباعة المباشرة لطابعة حرارية بلوتوث محتاجة تكامل إضافي حسب موديل الطابعة - كلمني لو عايز تضيفها بعدين.
- **الإهلاك/البنود الشهرية**: لما تسجل مصروف وتفعّل "بند شهري متكرر"، التطبيق هيتأكد كل مرة يفتح إن نفس البند اتسجل لشهر النهاردة، ولو لأ هيسجله تلقائي.

## 1. التثبيت

```bash
pip install -r requirements.txt
```

لو ظهرت `externally-managed-environment`: أضف `--break-system-packages`، أو استخدم virtual environment.

## 2. تجربة التطبيق على الكمبيوتر

```bash
flet run main.py
```

## 3. تجربته كموقع محلي على شبكة المحل

```bash
flet run --web main.py
```

للوصول من موبايل على نفس الواي فاي:

```bash
python3 -c "import flet as ft; import db; db.init_db(); db.apply_recurring_expenses(); from main import main; ft.run(main, view=ft.AppView.WEB_BROWSER, host='0.0.0.0', port=8550)"
```

وافتح من الموبايل: `http://<IP الكمبيوتر>:8550`

## 4. بناء تطبيق أندرويد (APK)

```bash
flet build apk
```

يحتاج JDK 17 و Android SDK (بيتثبتوا تلقائي أول مرة) و Git مثبت على الجهاز. الملف الناتج هيكون في `build/apk/app-release.apk`.

## هيكل الملفات

```
shop_app/
├── main.py             # نقطة الدخول + القائمة الجانبية + الثيم
├── db.py                # كل التعامل مع قاعدة البيانات SQLite
├── sales_view.py         # شاشة البيع (نقطة البيع)
├── products_view.py      # شاشة المنتجات
├── expenses_view.py      # شاشة المصروفات والسلف
├── deferred_view.py      # شاشة الإيرادات المؤجلة
├── returns_view.py       # شاشة المرتجعات
├── monthly_view.py       # شاشة جدول الشهر
├── reports_view.py       # شاشة التقرير اليومي
├── requirements.txt
└── shop.db               # بيتعمل تلقائي أول تشغيل
```

## أفكار للتوسيع لاحقاً

- طباعة فاتورة عن طريق طابعة حرارية بلوتوث (ESC/POS)
- تصدير جدول الشهر لملف Excel
- نسخة احتياطية تلقائية لملف `shop.db`
- دعم أكتر من مستخدم بصلاحيات مختلفة (كاشير / مدير)
